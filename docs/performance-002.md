# Performance report: FreeSpace 002 (10 million nodes)

**Date**: 2026-11-16 | **Feature**: `002-native-ui-redesign` | **Tasks**: T048, T066

## Environment

| Component | Value |
|-----------|-------|
| CPU | AMD Ryzen 7 6800H, 8 cores / 16 threads |
| OS | Windows 11 x64 |
| Rust | stable 1.93, `dev` profile (workspace crates `opt-level = 0`, dependencies `opt-level = 2`) |
| Browser | Chromium 159 (Playwright), 1600×900, device scale factor 1 |

## Method

- Synthetic tree: `cargo run --release -p freespace-app --example gen_fixture -- 10000000`.
  The example builds one arena with one million-node-sized directories and files,
  then measures the backend operations the interface calls.
- Treemap request: 1600×900, metric `on_disk`, `max_depth = 6`,
  `min_tile_px = 4`, `max_tiles = 2000` (the contract maximum used by the screen).
- Canvas draw: 2 000 rectangles on a 1600×900 canvas in Chromium, 120 frames;
  median, p95 and maximum frame draw time are reported.

## Backend measurements (10 039 063 nodes)

| Metric | Result | Budget | Status |
|--------|--------|--------|--------|
| Tree build (arena + names + totals) | 6 095 ms | — | — |
| `tree_root` page (500 rows) | 1 ms | ≤ 200 ms | PASS |
| `treemap_tiles` aggregation (2 000 tiles) | 102 ms | ≤ 200 ms | PASS |
| Node arena (`FsNode` = 176 bytes) | ≈ 1.77 GB | — | — |
| Name arena | 170 MB | — | — |
| Estimated tree memory (arena + names + capacities) | ≈ 2.0 GB | ≤ 4 GB total | PASS (backend) |
| Treemap payload | 2 000 tiles, `truncated = true` | ≤ 10 000 tiles | PASS |

At 1 000 000 nodes the same example reports 543 ms build and 81 ms Treemap
layout; the aggregation cost grows with the number of siblings, not with the
whole tree, because only the requested level is laid out.

## Canvas measurements

| Metric | Result | Budget | Status |
|--------|--------|--------|--------|
| Frame draw, 2 000 tiles, median | 0.9 ms | ≤ 33 ms (30 fps) | PASS |
| Frame draw, 2 000 tiles, p95 | 9.0 ms | ≤ 33 ms | PASS |
| Frame draw, 2 000 tiles, maximum | 14.3 ms | ≤ 33 ms | PASS |

The canvas never receives the full tree: Rust aggregates to at most `max_tiles`
rectangles, so the renderer cost is bounded independently of the node count.

## Memory budget

The backend tree plus name arena fits in about 2 GB for 10 million nodes. The
remaining budget in the 4 GB limit is reserved for WebView2/Chromium (typically
250–500 MB for this application), the interface stores (pages are capped at
2 000 rows) and the Tauri runtime. The page size and tile budget protect the
frame budget on the WebView side.

## Startup and interface memory (T182, T183)

Measured on the production build (`npm run build` + `vite preview`) with Playwright Chromium at
1440×900, mock transport, three runs:

| Metric | Result | Budget |
|--------|--------|--------|
| First contentful paint | 24–48 ms | — |
| Shell visible (h1, bootstrap applied) | 138–211 ms | ≤ 3 s |
| First screen with data (dashboard volumes) | 143–216 ms | ≤ 5 s |
| DOM nodes on the dashboard | 205 | — |
| JS heap after bootstrap | ≈ 10 MB | — |

The boot script applies theme, language and reduced motion before the first paint, so the shell
never renders a wrong theme and needs no second layout pass. Pages are capped at 2 000 rows, the
treemap at `max_tiles`, and each screen drops its page arrays and tile buffers when it unmounts
(`ui/src/stores/`), so memory does not grow with navigation.

## Reproduce

```powershell
cargo run -p freespace-app --example gen_fixture -- 10000000
npm --prefix apps/freespace-desktop/ui run test:e2e
npm --prefix apps/freespace-desktop/ui run test:visual
```

The browser draw measurement is part of the visual regression suite workflow;
the script above can be repeated with Playwright Chromium if the hardware
changes.

## Open items

- Release-profile numbers are expected to be lower; the report uses the `dev`
  profile that developers run every day, so it is a conservative bound.
- Full-process memory (Rust + WebView2) must be re-measured on the release
  installer before shipping (T169); the backend share is fixed by this report.
- DPI 125/150/200%, both themes and both languages are covered by the full 384-cell visual matrix
  (`apps/freespace-desktop/ui/tests/visual/matrix.spec.ts`); the gallery is generated by
  `npm run gallery`.
