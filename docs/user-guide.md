# Руководство пользователя FreeSpace 1.2

FreeSpace — нативная утилита для Windows 10/11, которая анализирует занятое место на дисках,
показывает деревья и карты, находит дубликаты, помогает безопасно освобождать пространство и
полностью работает офлайн.

## Установка и запуск

- Портативная сборка: распакуйте ZIP в любую папку и запустите `freespace-gui.exe`. В архиве нет
  интеграции с контекстным меню; настройки, журнал, кеш и карантин находятся в папке `data` рядом
  с исполняемым файлом.
- Установщик: запустите `FreeSpace_1.2.0_x64-setup.exe` (имя содержит версию). Установщик Tauri
  NSIS ставит совместимый WebView2 офлайн и не создаёт пунктов контекстного меню. Все данные
  приложения находятся в `data` рядом с исполняемым файлом.
- Портативная сборка без вложенного `webview2` использует системный WebView2; если нужен полностью
  автономный запуск, положите рядом распакованный fixed runtime в папку `webview2`.
- `%APPDATA%`, `%LOCALAPPDATA%`, `%ProgramData%` и временные каталоги не используются. Если папка
  приложения доступна только для чтения, настройки действуют до закрытия, а при сохранении
  выводится ошибка; приложение не переключается на системный каталог.
- Требуется Windows 10 21H2+ или Windows 11, x64. Права администратора нужны только для MFT-скана
  целых томов, доступа к защищённым системным каталогам и установки для всех пользователей.

## Первый запуск

1. Откройте страницу **Диски** — дашборд покажет все тома, занятое и свободное место, файловую
   систему и динамику по сохранённым снимкам.
2. Нажмите **Анализировать этот том**, чтобы запустить сканирование и перейти к дереву.
3. Изучите **Дерево** и **Карту**: размеры, доли, типы файлов, переход по «хлебным крошкам».

## Основные экраны

- **Сканирование** — выбор тома или каталога, метода (`auto`, `mft`, `walk`) и исключений.
- **Дерево** — сортировка, фильтр по имени и владельцу, раскрытие узлов, точные размеры.
- **Карта** — пропорциональные прямоугольники, подсветка категорий, зум.
- **Крупнейшие файлы** и **Типы** — топ объектов и распределение по расширениям.
- **Дубликаты** — побайтовая проверка, правило выбора копии, перемещение лишних копий в карантин.
- **Очистка** — рекомендации по временным данным, кешам, журналам, резервным копиям и устаревшим
  файлам; пустые каталоги.
- **Снимки** — сохранение состояния тома и сравнение двух снимков.
- **Точный размер** — логический, занятый и физический размер, сжатие, ссылки, ADS.
- **Длинные пути** — операции над путями длиннее 260 символов без системной политики.
- **Метаданные** и **Владельцы** — EXIF, медиа, версии PE; распределение места по владельцам.
- **Архивы** — просмотр ZIP/7z/TAR/ISO/RAR без распаковки и экспорт списка.
- **Экспорт** — CSV, XML, HTML и XLSX с выбором разделов.
- **Разблокировка** — поиск процессов, удерживающих файл, мягкое закрытие или завершение.
- **Шредер** — необратимое затирание файлов с предупреждением о SSD.
- **Мониторинг записи** — процессы, которые пишут на диск, скорость, пороги и история.
- **Права доступа** — текущий режим, защищённые каталоги и перезапуск с правами администратора.
- **Настройки** — язык, тема, единицы, исключения, пороги, карантин и включение пунктов
  контекстного меню (по умолчанию выключено).

## Интерфейс и доступность

- 24 экрана доступны из бокового меню, палитры команд (`Ctrl+K`) и глубоких ссылок; последний
  экран восстанавливается после перезапуска.
- Тёмная, светлая и системная тема переключаются без перезапуска; системная тема Windows
  подхватывается на лету. Поддерживаются DPI 100/125/150/200% и уменьшение движения.
- Все действия доступны с клавиатуры: skip-link, стрелки в дереве и на карте, `Enter` для
  открытия, `Esc` для возврата, возврат фокуса после диалогов. Narrator получает заголовки,
  прогресс и ошибки через `aria-live`.
- Язык RU/EN переключается в настройках без потери состояния; числа, даты и размеры
  форматируются правилами выбранного языка.
- Статус никогда не передаётся только цветом: у состояний есть текст и иконка.

## Безопасность

- Удаление всегда проходит через предпросмотр и подтверждение; способ удаления выбирается явно:
  Корзина, карантин FreeSpace или безвозвратное удаление.
- Защищённые системные пути требуют дополнительного подтверждения и повышения прав.
- Каждая разрушающая операция записывается в журнал; карантин можно восстановить.
- Операции над реальными пользовательскими файлами выполняются только по явной команде
  пользователя. Тесты используют временные каталоги и тестовые VHD.

## Контекстное меню и удаление

- После установки пунктов FreeSpace в контекстном меню нет. Включите их в **Настройках** или
  командой `freespace config set context_menu_enabled true`, выключите обратной командой.
- Удалить записи без удаления приложения: `freespace context-menu uninstall --all`.
- Деинсталлятор Tauri NSIS удаляет исполняемые файлы, каталог `data`, профиль WebView2 и пункты
  меню для текущего пользователя. Портативная сборка не содержит команды `context-menu` и не
  создаёт записей в реестре.

## Командная строка

CLI повторяет возможности GUI и выдаёт JSON. Подробности и коды возврата — в [cli.md](cli.md).

```powershell
freespace drives --json
freespace scan C:\ --json
freespace tree C:\ --depth 2 --json
freespace duplicates D:\Downloads --json
freespace monitor --threshold 1073741824 --json
freespace config set language ru
```

Параллельные запуски сериализуются блокировкой; `--lock-timeout` задаёт ожидание. Команды,
изменяющие данные, требуют `--yes` в неинтерактивном режиме.

## Приватность

FreeSpace не делает сетевых вызовов, не отправляет телеметрию и не требует учётной записи. Все
данные остаются на компьютере. Регрессионный тест `tests/privacy.rs` проверяет это на уровне
исходного кода и зависимостей.

## Решение проблем

- **Недоступные каталоги**: ограниченный режим помечает их в дереве; откройте страницу
  **Права доступа** и перезапустите приложение от имени администратора.
- **MFT недоступен**: для FAT32/exFAT используется обход каталогов, для NTFS без прав —
  автоматический fallback.
- **Мониторинг без путей**: без прав администратора ETW недоступен, поэтому показываются счётчики
  процессов и подсказки путей из журнала USN.
- **Настройки не сохраняются**: проверьте права на папку `data` рядом с исполняемым файлом или
  распакуйте приложение в доступный для записи каталог. Резервного сохранения в `%APPDATA%`,
  `%LOCALAPPDATA%` или `%ProgramData%` нет.
- **Пунктов нет в контекстном меню**: включите `context_menu_enabled` в настройках; портативная
  сборка не поддерживает контекстное меню.
