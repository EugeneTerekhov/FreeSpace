# Контракт: форматы отчётов FreeSpace

**Feature**: `001-freespace-disk-analyzer` | **Version**: 1 | **Date**: 2026-11-15

Отчёты содержат одинаковый набор данных и различаются только представлением. Любой формат MUST
сохранять согласованность сумм с приложением (FR-070…FR-073, SC-009).

## Общие метаданные

Каждый отчёт содержит секцию метаданных:

| Поле | Описание |
|------|----------|
| `report_version` | Версия схемы отчёта (`1`) |
| `generated_at` | Дата и время (ISO 8601, UTC) |
| `app_version` | Версия приложения |
| `volume` | Том: метка, буква, файловая система, метод сканирования |
| `roots` | Проанализированные области |
| `session_id` | Идентификатор сессии |
| `units` | `binary` или `decimal` |
| `sections` | Включённые разделы |

## Раздел `tree`

Иерархический список узлов.

| Колонка | Тип | Описание |
|---------|-----|----------|
| `path` | строка | Полный путь |
| `name` | строка | Имя |
| `kind` | строка | file/dir/link |
| `logical_size` | u64 | Логический размер |
| `on_disk_size` | u64 | Размер на диске |
| `physical_size` | u64 | Физический размер |
| `files` | u64 | Количество файлов в поддереве |
| `dirs` | u64 | Количество каталогов в поддереве |
| `modified` | ISO 8601 | Дата изменения |
| `attributes` | строка | Атрибуты через запятую |
| `owner` | строка | Владелец |

## Раздел `top`

| Колонка | Тип |
|---------|-----|
| `rank` | u32 |
| `path` | строка |
| `size` | u64 |
| `modified` | ISO 8601 |

## Раздел `types`

| Колонка | Тип |
|---------|-----|
| `extension` | строка (`<none>` для файлов без расширения) |
| `category` | строка (video/archive/image/audio/document/system/other) |
| `count` | u64 |
| `total_size` | u64 |
| `share` | f64 (0..1) |

## Раздел `duplicates`

| Колонка | Тип |
|---------|-----|
| `group_id` | строка |
| `hash_algorithm` | строка |
| `hash` | строка |
| `size` | u64 |
| `path` | строка |
| `keep` | bool |
| `selected` | bool |
| `reclaimable_bytes` | u64 (в первой строке группы) |

## Раздел `owners`

| Колонка | Тип |
|---------|-----|
| `owner` | строка |
| `sid` | строка |
| `files` | u64 |
| `total_size` | u64 |

## CSV

- Кодировка UTF-8 с BOM (для корректного открытия в Excel).
- Разделитель — запятая; значения с разделителями, кавычками и переводами строк экранируются.
- Первая строка — заголовки; при нескольких разделах каждый раздел оформляется отдельным блоком
  с строкой-заголовком `# section: <name>` и пустой строкой между блоками.
- Числа — без разделителей тысяч; размеры в байтах; даты — ISO 8601.

## XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<freespace-report version="1">
  <meta>
    <generated-at>2026-11-15T12:00:00Z</generated-at>
    <app-version>1.0.0</app-version>
    <volume letter="C" label="System" filesystem="NTFS" scan-method="mft"/>
    <roots><root>C:\</root></roots>
  </meta>
  <sections>
    <section name="tree">
      <node path="C:\" kind="dir" logical-size="0" on-disk-size="0" files="0" dirs="0"/>
    </section>
    <section name="top">...</section>
    <section name="types">...</section>
    <section name="duplicates">...</section>
    <section name="owners">...</section>
  </sections>
  <totals logical-size="0" on-disk-size="0" physical-size="0"/>
</freespace-report>
```

- Схема описана в документированном XSD-подобном виде; имена элементов в kebab-case.
- Все размеры — целые байты; `share` — число с плавающей точкой.

## HTML

- Самодостаточный файл: встроенные стили, без внешних ресурсов и сетевых запросов.
- Секции: сводка (объём, число файлов, метод), дерево (сворачиваемое), топ-файлы, типы,
  дубликаты, владельцы.
- Экранирование всех пользовательских строк обязательно.
- Для больших отчётов дерево ограничивается настраиваемой глубиной, полный список доступен в CSV.

## XLSX

Листы:

1. `Summary` — метаданные и итоги.
2. `Tree` — раздел `tree`.
3. `TopFiles` — раздел `top`.
4. `Types` — раздел `types`.
5. `Duplicates` — раздел `duplicates`.
6. `Owners` — раздел `owners`.

Требования: замороженная строка заголовков, автофильтр, числовой формат для размеров, даты в
формате ISO 8601, отсутствие формул, корректное открытие в Microsoft Excel и LibreOffice Calc.

## Ограничения

- Отчёты не содержат содержимого файлов, хешей целых файлов (кроме раздела дубликатов) и
  персональных данных, кроме имён владельцев.
- При экспорте отчёта на миллионы строк запись MUST быть потоковой; приложение MUST NOT
  исчерпывать память.
